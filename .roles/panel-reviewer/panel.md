# Healthcare Access Peer Panel (illustrative)

Archetype peer reviewers for SHIELD research outputs — distinct from the parliament (adversarial design review) and the editorial gate (form review). Each is an archetype, not a named person.

| ID | Reviewer archetype | Expertise |
|---|---|---|
| R-P1 | Health-system planner | Facility networks, referral regions, access planning |
| R-P2 | Network scientist | Referral/transfer/catchment topology, graph algorithms, resilience |
| R-P3 | Health economist | Payer mix, benefit-cost, coverage, provider markets |
| R-P4 | Operations / health-services researcher | ED flow, capacity, workforce, appointment access, surge |
| R-P5 | Public-health / equity scholar | Shortage areas, disparities, prevention, community outcomes |

Assignment guide:

- Topology / resilience method → R-P2, R-P4
- Capacity / wait time / operations → R-P4, R-P1
- Payer economics / consolidation / benefit-cost → R-P3
- Equity / shortage areas / public health → R-P5, R-P1
- Tier/SLA + multi-scale methodology → R-P1, R-P4
